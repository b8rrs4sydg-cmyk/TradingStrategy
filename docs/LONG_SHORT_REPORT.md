# 多空策略研究報告（目標：年化 ≥ 15%、MDD < 15%、多幣種、通過蒙地卡羅）

> 結論先講：**目前沒有找到能穩健達標的多空策略。** 在設計用的幣池 A 上看起來達標的設計，
> 換到從未見過的幣池（B：49 幣；C：236 幣）就失效。以下完整記錄研究過程、所有數字與失敗原因，
> 以避免把過擬合的結果當成可用策略。
>
> 所有回測：Freqtrade 2026.9 期貨模式（USDT-M 永續，含真實資金費率與標記價格，手續費 0.1%/邊），
> 權益以 `research/analyze.py` 由訂單逐筆重建的**逐時市值**計算（Freqtrade 期貨錢包不含未實現損益，會低估波動與回撤）。

## 1. 驗證架構

| 資料 | 用途 | 狀態 |
|---|---|---|
| 幣池 A（50 主流幣）2020-06 → 2023-12 | 設計 / 參數敏感度 / 置換檢定 | in-sample |
| 幣池 A 2024-01 → 2026-09 | 樣本外 | 第一次凍結後使用 |
| 幣池 B（49 幣）2020-06 → 2026-09 | holdout | 第一次凍結後使用 |
| **幣池 C（236 幣）2020-06 → 2026-09** | **最終乾淨 holdout** | 依固定規則選出（所有不在 A/B、上市 ≥ 2 年的 USDT 永續），兩個設計凍結後才首次使用 |

## 2. 研究歷程

### 2.1 策略家族比較（向量化實驗室，幣池 A in-sample，目標波動 12%）

| 家族 | CAGR | MDD | Sharpe |
|---|---|---|---|
| 時間序列趨勢 TSMOM 20/60/120 | 16.0% | 9.3% | 1.14 |
| Donchian 50/20 | 19.4% | 8.5% | 1.42 |
| 橫截面動能 30 日（市場中性） | 19.0% | 13.5% | 1.40 |
| 橫截面短期反轉 7 日 | −32.0% | 75.7% | −2.91 |

### 2.2 TrendMomentumLS（趨勢 + 橫截面動能 + 資金費率因子，三分支等權）

- 三分支日報酬相關係數 −0.04 ~ 0.09，組合後實驗室 Sharpe 1.98。
- 參數敏感度：24 + 15 組全部獲利；**置換檢定 p = 0.003**；**參數隨機擾動 200 組**：Sharpe p5 1.48、全部獲利（皆為 in-sample）。
- 依事先宣告規則（in-sample MDD ≤ 10% 下 CAGR 最高）凍結目標波動 10%（commit `da61a54`）。

| Freqtrade | 目標波動 | CAGR | MDD | Sharpe |
|---|---|---|---|---|
| A in-sample 2020-06→2023-12 | 10% / 12% / 14% | 12.9 / 15.5 / 18.1% | 8.6 / 10.1 / 11.7% | 1.22–1.24 |
| A 樣本外 2024-01→2026-09 | 10% / 12% / 14% | 12.5 / 14.9 / **17.3%** | 9.6 / 11.0 / **12.4%** | 1.06–1.09 |
| **B holdout** | 10% | **−2.6%** | **25.7%** | −0.22 |
| **C holdout** | 10% | 2.0% | **31.5%** | 0.19 |

A 的樣本外看似達標，但 2025 年 +19% 中有 1,486 USDT 來自單一幣種 ZEC；B、C 皆失敗。
分支拆解：**橫截面動能自 2023 年後衰退**（A：2024–26 連三年負報酬；B：Sharpe −1.0），資金費率因子僅在 A 有效。

### 2.3 DonchianTrendLS（純趨勢，Donchian 20/10、50/20、100/50 集成）

在 A+B in-sample 上，唯一兩個幣池都為正的家族是時間序列趨勢，因此改以 A+B 同時開發（commit `4edc87a` 凍結）。

| Freqtrade | 目標波動 | CAGR | MDD | Sharpe |
|---|---|---|---|---|
| A in-sample | 12% / 15% | 12.9 / 16.1% | 8.7 / 10.7% | 1.06 |
| B in-sample | 12% / 15% | 4.6 / 6.0% | 8.6 / 10.7% | 0.47 |
| **C holdout（乾淨）** | 12% / 15% | **−0.2 / −0.2%** | **19.9 / 23.0%** | 0.03 |

## 3. 為什麼失敗

1. **優勢只存在於大型、高流動性幣種**：A（主流 50 幣）上成立，B（二線）明顯變弱，C（大量小幣、迷因幣）消失。
   幣池 A 本身是「現在的前 50 名」，含後見之明（如 SUI、APT），會高估績效。
2. **橫截面動能在 2023 年後衰退**：這是 2020–2022 年最強的報酬來源，之後持續失效。
3. **小幣的極端報酬破壞波動目標**：C 上 TrendMomentumLS 實際波動 18.5%（目標 10%），回撤因此放大到 31%。
4. **Freqtrade 執行比理論模型差**：實驗室 Sharpe 約為 Freqtrade 的 1.4–1.6 倍（最小下單量、再平衡帶、逐筆手續費）。

## 4. 誠實的結論與建議

- 在「多幣種、多空、年化 15%、MDD < 15%」的條件下，**沒有任何設計通過乾淨的跨幣池驗證**。若只看幣池 A 或
  只看樣本外 A，可以宣稱「年化 17%、MDD 12%」——但那正是本專案要避免的過擬合。
- 目前唯一通過所有驗證（樣本外 + 未見幣池 + 蒙地卡羅）的仍是 **FundingCarry**（年化約 5–6%、MDD < 6%）。
- 若要繼續，可行方向（都需要新的乾淨驗證資料，例如 2026-10 之後的實盤模擬）：
  1. 只交易「當時」市值/成交量前 20–30 的主流幣（以當時資料動態決定，避免後見之明），並以 dry-run 前瞻驗證；
  2. 趨勢策略與 FundingCarry 組合（兩個 bot、資金分配），以降低回撤、提高穩定度，但預期年化低於 15%；
  3. 接受較低的報酬目標（例如年化 8–10%、MDD < 10%）。
