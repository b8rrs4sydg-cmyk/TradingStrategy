# 智慧化進階機票搜尋與策略規劃系統 — 產品規格書

## 1. 系統定位與核心目標

打破傳統 OTA（線上旅行社）只能查固定點對點的限制，允許使用者以「假期」為核心，
結合國家清單、特休策略與進階票規，自動運算並組合出性價比最高、
請假效益最大化的機票組合。

## 2. 核心功能規格

### 2.1 假期與彈性日期矩陣模組 (Holiday & Date Matrix Module)

- **2027 台灣連假資料庫整合**：內建行政院人事總處公告之 2027 年所有連假
  （元旦、春節、228、清明、勞動節、端午、中秋、國慶等）以及「請假攻略」組合
  （如：春節請 2 休 11、清明請 3 休 9）。
- **自定義日期與 ±N 天彈性視窗**：使用者選定某個連假或自訂日期區間後，
  可設定去程與回程各可彈性增減的天數（例：去程 ±2 天，回程 ±3 天）。
  系統自動展開所有可能的日期矩陣。

### 2.2 多段旅程與多國目的地規劃 (Multi-Leg & Multi-Destination)

- **多國比較**：一次勾選多個國家/機場（例：日本全區、韓國、泰國），
  尋找該假期間哪一個目的地的機票組合最划算。
- **多段旅程 (Multi-city / Open-Jaw)**：支援規劃 M 段旅程
  （例：TPE→NRT，幾天後 NRT→KIX，最後 KIX→TPE），或中途停點（Stopover）規劃。

### 2.3 進階票規與策略引擎 (Advanced Ticketing Strategy Engine)

本系統最具價值的核心：

- **反向票 / 倒置票規劃 (Reverse Ticketing)**：針對某些航線 A→B→A 比 B→A→B 便宜，
  或需要利用背對背 (Back-to-back) 邏輯破解鎖定票價的情況，系統自動計算反向開票的可能性
  （例：先買一張由外站出發的年票/半年票的第一段，或利用不同方向的混搭）。

- **四段票 / 外站出發規劃 (4-Leg Out-of-Station / Back-to-Back)**：
  針對經典「外站四段票」架構（例：`XMN-TPE-NRT-TPE-XMN`），系統自動配對：

  1. **票甲（頭尾段）**：由外站飛回台灣，再飛回外站（保留未來要用的票）。
  2. **票乙（中間段）**：在台灣連假期間，利用票甲夾在中間的時間，
     合法且流暢地完成真實的國際旅行。

  系統計算「兩張票的總價」是否低於「直接買單程/傳統來回」，
  並提示銜接時間（Minimum Connection Time, MCT）是否安全。

### 2.4 最佳化排序與推薦引擎 (Optimization & Scoring Engine)

多維度評分權重（可由使用者自訂）：

- 絕對價格優先（Total Cost）
- 請假效益比（每請 1 天特休換得的遊玩時數/金錢成本）
- 飛行時數/轉機次數
- 策略複雜度（直飛 > 一般轉機 > 四段票/反向票需注意風險）

## 3. 技術堆疊

- **Frontend**：React / Next.js (TypeScript) + Tailwind CSS + Shadcn UI
- **Backend**：Python (FastAPI)
- **Database**：PostgreSQL（設定、歷史、連假對照表）
- **Cache**：Redis（航班價格快取）
- **Flight Data**：Amadeus Self-Service API / Skyscanner API (RapidAPI) + 輔助爬蟲
